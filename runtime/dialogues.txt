#  桌宠 · 本地文本池
# ============================================================================
#
#  怎么改：
#    用任意文本编辑器（记事本也可以）直接改这个文件并保存，然后回到桌宠点一下
#    角色即可生效 —— 不需要重新编译，也不需要重启程序。
#
#  格式：
#    #  开头        → 整行是注释，程序会忽略
#    空行          → 忽略，随便用来分组都行
#    [分类名]      → 分类开始；它下面的每一行都是该分类的一条文本
#    其他行        → 一条独立文本（首尾空格会被去掉）
#
#  注意：
#    - 文件必须保存为 UTF-8 编码。如果存成 GBK 等其它编码，程序会明确报错，
#      不会静默乱码。
#    - [click] 是点击角色时用的分类。这个分类必须存在，否则程序会报错且不弹气泡
#      （不会用程序自编的台词顶替）。
#    - 台词数量不限；同一条不要在两行里重复，重复会被当成两条独立内容。
#
# ============================================================================
