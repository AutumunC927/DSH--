# dsh-live2d-pet · Live2D 桌宠工坊

给一份 Live2D 素材，直接得到一个能跑的 Windows 桌面宠物。

**给 DSH 用的工具，给画师用的成品。** 不需要懂电脑，也不需要装任何开发环境。

| | |
|---|---|
| **平台** | 仅 **Windows 10 / 11 x64**（不支持 macOS / Linux） |
| **体积** | 约 161 MB，其中 160 MB 是预编译引擎 |
| **依赖** | **无**。不需要 .NET、VC++ 运行库，或任何编译器 |
| **美术资产** | **不含任何模型与贴图** —— 由使用者自己提供 |
| **联网** | 生成与运行桌宠**全程不联网**，无遥测、无自动更新 |
| **安装脚本** | 无（`package.json` 里没有 `scripts` 字段） |

---

## 怎么用

把仓库链接丢给 DSH 就行：

```
装一下这个 https://github.com/AutumunC927/dsh-live2d-pet
```

装好后会多出 5 个 `pet_` 开头的工具，然后**只要告诉它模型文件夹在哪**
（就是含有 `.model3.json` 的那个目录）。剩下的它会做。

> 装完需要**重启一次 DSH** 才会生效。

## 它安全吗

**自己核，不用信我们。** 四条命令，跑完就知道：

```bash
grep -rn "fetch\|http\|net\.\|WebSocket" entry.js lib/     # 预期无输出（不联网）
grep -rn "eval(\|new Function" entry.js lib/               # 预期无输出（无动态代码）
grep -rn "execFileSync\|child_process" entry.js lib/       # 预期恰好 2 处（快捷方式 / zip）
node -e "console.log(require('./package.json').scripts)"   # 预期 undefined（无安装脚本）
```

**我们主动交代两件事**，不藏着：

1. **确实有 2 次 `powershell.exe` 调用**（建 `.lnk` 要 COM、打 zip 要 .NET `ZipFile`，
   Node 都没这能力）。用的是 argv 数组而非 shell 拼接，不存在命令注入。
2. **如果你的环境不允许任何 shell 调用，就不要装本插件** ——
   这一点宁可提前讲清楚，也不想让人装完才发现。

完整清单、解释与更多核对命令见 [`SECURITY.md`](./SECURITY.md)。

动作参数被烘进基准、表达式与直接改参数混用导致叠图层。

这些都被封进引擎里了。使用者只需要关心**素材对不对**。

## 用法

在 DSH 里说一句「用这个文件夹做个桌宠」并给出模型目录即可。插件会：

1. **预检素材**（`pet_check_assets`）
   模型数据、定义文件、贴图、贴图格式与尺寸、表情/动作/物理是否存在。
   报错**只谈美术资源**，而且每条都写清「改哪个文件、怎么改」。

2. **一键产出**（`pet_create`）
   复制引擎 → 放入模型 → 写运行期配置 → 桌面快捷方式。
   默认还会给出可直接发给别人的 zip（`zip: true`）。

3. **收尾工具**
   `pet_shortcut`（补一个快捷方式）、`pet_zip`（打包）、`pet_info`（看当前配置）。

### 工具一览

| 工具 | 作用 |
|---|---|
| `pet_check_assets` | 素材预检。生成前先跑它。 |
| `pet_create` | 一键产出桌宠（含预检、快捷方式，可选 zip）。 |
| `pet_shortcut` | 给已有桌宠补桌面快捷方式。 |
| `pet_zip` | 打包成 zip。 |
| `pet_info` | 查看某个桌宠的配置。 |

### 裁剪造型与动作

生成时传 `looks` / `exclude_looks` / `actions`；
也可以事后改桌宠目录下的 `pet.config.json`：

```json
{
  "model": "Haru",
  "name": "小春",
  "excludeLooks": ["F03"],
  "actions": ["idle", "m01"]
}
```

造型 = 模型里全部 `.exp3.json`，动作 = 全部 `.motion3.json`，
**按名字自动枚举，不依赖任何模型专属列表**（这是通用化的关键：
早先按固定名字表实现时，换一个模型就全部匹配不上）。

## 产出的桌宠

* 透明无边框窗口，角色可拖动
* 点角色弹气泡（台词在桌宠目录的 `dialogues.txt`，改完即时生效，无需重启）
* 控制条 7 个按钮：锁定 / 玩偶 / 坐下 / 造型 / 睡觉 / 动作 / 退出
* **托盘图标**：左键双击显示/隐藏，右键菜单「显示/隐藏」「退出」
  （原生窗口不进任务栏，托盘是常驻入口）
* 锁定后鼠标穿透到下层应用；再点「解锁」恢复
* 首次启动自动在桌面放一个**快捷方式**（不是副本）

### 缺资源时会明确告诉你

**功能因为缺少美术资源而用不了时，桌宠会弹一个小提示条，写清楚缺什么** ——
不会出现「点了没反应」这种让人摸不着头脑的情况。

| 现象 | 提示内容 |
|---|---|
| 点角色不甩尾 | 没有可甩的尾巴（缺少 `ArtMesh438/439` 那一套尾巴参数） |
| 「玩偶」没变化 | 没有「抱玩偶」对应的部件（缺少 `n-` 表情文件） |
| 「坐下」没变化 | 没有「坐下」对应的部件（缺少 `Q` 表情文件） |
| 「动作」没变化 | 没有可播放的动作（缺少 `.motion3.json` 动作文件） |

提示是琥珀色的小卡片，贴在角色头顶，几秒后自动消失，不需要点掉。
甩尾那条每次运行只说一次，免得每次点角色都被打断。

### 发给别人

用 `pet_zip` 打包，对方解压后双击 `XiaoXiaoQiu.Pet.exe` 即可，无需安装任何东西。

## 边界

* **只支持 Windows x64**（引擎依赖 D3D11 + DirectComposition）。
* 引擎对模型的假设已尽量放宽，但仍会按**参数名**识别少数增强功能：
  尾巴（`ArtMesh438/439`）、抱玩偶（`n-` 表情）、坐下（`Q` 表情）。
  缺了就退化成「没有这个功能 + 明确提示」，**不影响模型正常显示与其它交互**。
* **不负责拓展动作/表情。** 需要更多互动、更多状态机，请让你的 DSH 会话基于
  桌宠目录自行开发 —— 那不属于本插件的职责范围。
* 素材的版权与 Live2D 授权由使用者自行负责。

---

## 为什么引擎不进编译器

引擎是**预编译**并随插件分发的：

* 自包含 .NET 10（含 WPF/WinForms 程序集）
* VC++ 运行库 app-local
* 预生成的着色器缓存（省掉首次启动约 10 秒的编译）

因此「导入素材 → 产出桌宠」是纯文件操作，秒级完成，且在任何干净的
Windows 10/11 x64 机器上都能跑 —— 包括没装过任何开发工具的机器。
